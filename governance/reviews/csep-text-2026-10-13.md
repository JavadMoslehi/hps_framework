## Bounds, ownership and resources

All raw text imports stop within caller-declared initialized extents including
NUL. Views reject length NPOS. Output arithmetic checks before add/multiply/index;
signed parse/render handle INT64_MIN without negation overflow. Token, padding and
replacement progress consumes a nonempty delimiter/pattern or terminates. Empty
patterns/counts have explicit behavior. Every failure preserves text, descriptor,
metadata outputs and transactional scratch. Runtime checks cannot prove dangling
pointers, forged actual extents or disjointness; these remain caller contracts.

Caller-owned scratch stages aliased source text for edits/formatting. Simpler
copy ranges use memmove. Algorithms that reread patterns during in-place compaction
or emit sequentially document disjoint inputs. Source policies receive uint8_t
values once, normalize their flag and validate alphabets before copied mutation.
Fixed storage owns a compile-time bounded real char array; a separate descriptor
borrows it, with explicit rebinding after moving/copying the object.

No module-owned mutable payload or state is added. Numerical formatting uses at
most 80 characters per fixed automatic scratch array; conversion uses65 and dump
uses21. Actual nested stack/ROM and libc/compiler dependencies require target
analysis. Policy test fixtures use 1,888 immutable bytes for59x256 membership bits.
Work is bounded by declared source/output capacities, with naive substring scans
potentially quadratic. No measured timing, target stack budget or WCET is claimed.

HPS-C-017/018: repeated range/case/numeric-width APIs are consolidated; private
helpers share checks, transform/copy and sizing/commit behavior. Cstr and view
split retain different empty-input contracts; forward/reverse searches have
different bounds/termination proofs. ASCII-octet helpers differ from execution-set
C-string table folding. Such distinct contracts justify the remaining specialized
paths. The59 private policy expressions preserve reviewable original alphabets.
