## Requirements, scope and migration

environment detection. Its 23 functions comprise borrowed counted views, exact
slices, unsigned-byte comparison, prefix/suffix tests, forward/reverse search,
trimming, bounded C-string import/export and caller-owned fixed-capacity C-string

the explicit before/after mapping from both legacy implementations. This is a
checked HPS adaptation, not a namespace-only migration. The native enum API is
preserved independently and is not rewritten to use the new string semantics.

## Contracts, bounds and resource review

Views borrow initialized characters in a live object; NULL requires length zero,
and `SIZE_MAX` is reserved as NPOS. Successful empty descriptors normalize to
NULL/zero without NULL pointer arithmetic. Exact slices use subtraction proofs.
Search absence is success plus NPOS; empty-needle semantics are explicit. Forward
search has a nonempty needle before its final position increment; reverse search
stops at zero before decrement. All failure paths preserve output objects.

Capacity includes NUL. Buffer state requires non-NULL storage, positive capacity,
length below capacity, the final NUL and no earlier NUL. Import scans only the
supplied bound; an exact-sized four-character object with no NUL tests this bound.
Assign/append validate state, source shape, available space and then source NUL
before any write. Subtraction proves additions and pointer offsets safe. `memmove`
allows overlapping payloads; metadata/payload overlap is a caller prohibition.
Erase moves a proved bounded suffix including NUL. Removed text is not wiped.
Runtime checks cannot verify forged extents, dangling pointers or actual ownership.

No heap, OS call, module-owned payload arrays, locks or mutable globals are added.
Only fixed-size automatic descriptors/counters are used; caller storage and its
maximum lengths/capacities are application budgets. Source work bounds are in the
headers/contract, including O(view length × needle length) naive search and
O(old length + source length) checked buffer writes. These are not timing/WCET or
measured stack claims. This host's string archive has external `memcmp`, `memmove`
and compiler `__stack_chk_fail` references, plus a cross-object string constructor
reference. Symbol inspection is not transitive whole-product no-heap proof.

HPS-C-017/018: shape/NUL checks, prefix/suffix matching and buffer assign/append
logic are shared where contracts match. Forward/reverse searches remain separate
because position bounds, empty-needle meaning and termination proofs differ.
Exact C-string export keeps its distinct destination/output validation contract.
